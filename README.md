# I Am Scientist Landing Page Clone

A responsive landing page clone built using React.js and modern frontend technologies.

## Features

* Responsive design
* Modern UI layout
* Smooth animations
* Reusable React components
* Mobile-friendly interface

## Technologies Used

* React.js
* JavaScript
* CSS3
* HTML5
* Framer Motion
* Vite

## Installation

1. Clone the repository

```bash
git clone https://github.com/your-username/iamscientist-landing-page-clone.git
```

2. Navigate to the project folder

```bash
cd iamscientist-landing-page-clone
```

3. Install dependencies

```bash
npm install
```

4. Run the development server

```bash
npm run dev
```
