# 🌐 I Am Scientist Landing Page Clone

## 📌 About Project
This is a **responsive landing page clone** inspired by iamscientist.ai, built using modern frontend technologies.

It focuses on **clean UI, responsiveness, animations, and reusable components**.

---

## 🚀 Features
- Fully responsive design 📱💻  
- Modern and clean UI 🎨  
- Smooth animations (Framer Motion)  
- Reusable React components  
- Mobile-friendly interface  
- Fast and optimized performance  

---

## 🛠️ Technologies Used
- React.js  
- Vite  
- JavaScript (ES6+)  
- Tailwind CSS  
- Framer Motion  
- HTML5 & CSS3  

---

## 📂 Project Structure
- src/components/Navbar  
- src/components/Hero  
- src/components/Sections  
- src/components/Footer  
- src/assets
